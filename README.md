## Description

This project demonstrates basic Dart programming using variables, data types, operators, and console output through a simple store purchase scenario.

## Program Features

The program demonstrates:

- `int` variable for quantity
- `double` variable for price
- `String` variable for customer name
- `bool` variable for membership status
- Arithmetic operator for calculating the total price
- Comparison operator for checking discount eligibility
- `print()` statements with readable output
